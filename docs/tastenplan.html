Sofle Tastenplan

Gleiche Tasten auf Omarchy und macOS. Linux bleibt beim Omarchy-Standard. Der Mac folgt über AeroSpace.

Drei Tasten, drei Aufgaben

Die Tastatur sendet für jede Aufgabe einen eigenen Code. Linux ordnet die Codes mit einer XKB-Option zu, die nur für die Sofle gilt. Der Mac braucht keine Zuordnung.

Kopieren, Speichern oder ein neuer Tab liegen damit auf beiden Systemen auf APP. Terminal-Befehle wie Abbrechen liegen auf beiden Systemen auf CTRL.

Die Ebenen der Tastatur

LOWER und RAISE sind Halte-Tasten am Daumen. Beide zusammen ergeben ADJUST.

Basis

WM liegt auf der Caps-Position. Die Daumen tragen ALT, CTRL und APP. Drehregler: links Lautstärke, rechts Scrollen.

LOWER

F-Tasten, Ziffern und Sonderzeichen. Die Caps-Position bleibt WM, damit WM + = funktioniert.

RAISE

Pfeile auf H J K L, darüber Home, Bild ab, Bild auf und Ende. Die linke Hand hält dazu ALT, CTRL, Shift oder APP. Die obere Reihe wählt das Bluetooth-Profil.

ADJUST (LOWER + RAISE)

Bluetooth, Beleuchtung sowie BOOT und RESET für beide Hälften.

Hotkeys mit gehaltener WM-Taste

Diese Belegung gilt auf beiden Systemen. Gestrichelte Tasten haben keine gemeinsame Funktion.

WM + Taste

WM + Shift + Taste

Der linke kleine Finger hält WM. Shift kommt deshalb von der rechten Hand.

Wo das eingestellt ist

  • Tastatur: config/sofle_choc_pro.keymap im Repository zmk-config.
  • Linux: hypr/custom.lua und die XKB-Option sofle:mods im Repository development-configurations.
  • Mac: .aerospace.toml im selben Repository. Karabiner gibt der eingebauten Tastatur die WM-Taste auf Caps Lock.
